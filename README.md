# Practical Statistics for Data Scientists

Repository ini berisi implementasi dan ringkasan materi dari buku
*Practical Statistics for Data Scientists, Second Edition*.

## Tujuan

Project ini dibuat untuk memahami konsep statistika yang digunakan
dalam data science dan machine learning melalui implementasi Python.

## Chapter

### Chapter 1 - Exploratory Data Analysis
Membahas eksplorasi data, statistik deskriptif, distribusi,
data kategorikal, korelasi, dan visualisasi.

### Chapter 2 - Data and Sampling Distributions
Membahas sampling, sampling distribution, standard error,
bootstrap, confidence interval, dan beberapa distribusi probabilitas.

### Chapter 3 - Statistical Experiments and Significance Testing
Membahas eksperimen statistik, A/B testing, hypothesis testing,
p-value, t-test, ANOVA, dan chi-square.

### Chapter 4 - Regression and Prediction
Membahas regresi linear, residual, evaluasi model,
pemilihan variabel, dan prediksi.
