## Deskripsi

Repository ini dibuat untuk memenuhi tugas reproduksi kode dan
pemahaman konsep dari buku *Practical Statistics for Data Scientists*.

Setiap chapter berisi:
- penjelasan singkat konsep,
- implementasi Python,
- visualisasi,
- hasil analisis,
- dan interpretasi dari output yang diperoleh.

## Daftar Chapter

### Chapter 1 — Exploratory Data Analysis

Membahas proses eksplorasi data, statistik deskriptif, ukuran
penyebaran, distribusi data, outlier, data kategorikal, korelasi,
dan hubungan antarvariabel.

File:
`PracticalStatisticsChapter1.ipynb`

### Chapter 2 — Data and Sampling Distributions

Membahas population dan sample, random sampling, sampling distribution,
standard error, bootstrap, confidence interval, normal distribution,
t-distribution, binomial distribution, dan Poisson distribution.

File:
`PracticalStatisticsChapter2.ipynb`

### Chapter 3 — Statistical Experiments and Significance Testing

Membahas A/B testing, hypothesis testing, permutation test, p-value,
t-test, ANOVA, dan chi-square test.

File:
`PracticalStatisticsChapter3.ipynb`

### Chapter 4 — Regression and Prediction

Membahas simple linear regression, multiple linear regression,
prediksi, residual, R-squared, RMSE, serta perbandingan nilai aktual
dan hasil prediksi.

File:
`PracticalStatisticsChapter4.ipynb`

## Cara Menjalankan

1. Buka salah satu file `.ipynb`.
2. Pilih **Open in Colab** atau upload file ke Google Colab.
3. Jalankan cell dari atas ke bawah.
4. Pastikan semua output dan visualisasi muncul tanpa error.
